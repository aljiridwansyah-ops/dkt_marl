# Hasil eksperimen ulang DKT–MARL

Simpan CSV agregat dan `run_manifest.json` dari ZIP ekspor pada `results/fresh-rerun/<RUN_ID>/<MODE>/`. Untuk rerun pertama, gunakan `rerun-001/kc_smoke/` dan `rerun-001/kc_audit/` sesuai mode yang dijalankan.

Dataset mentah, checkpoint, prediksi per mahasiswa, dan manifest split privat disimpan di Drive. Saat folder ini dibuat, eksperimen menunggu eksekusi di Colab.
